# Resource leases v1
Source `common/.harness/lib/resource-leases.sh`, then call `harness_lease_acquire <session-id> <wait-seconds> <request-tsv>` or `harness_lease_release <lease-token>`.
The request is non-empty LF-terminated TSV with columns `domain`, `canonical_id`, and `mode`. Legal pairs are `workspace+source`, `workspace+build`, `android+device`, and `android+cvd`. Workspace IDs are `realpath` values relative to the caller's PWD and must contain no ASCII control byte. Android IDs are safe `android-instance-id` components, never ADB serials or CVD names. Rows normalize in C order and the complete bytes use SHA-256; duplicate normalized keys are invalid.
The state root is `$HARNESS_RESOURCE_LEASE_ROOT` when non-empty, otherwise `${XDG_RUNTIME_DIR:-/tmp}/aosp-harness-resource-leases-$EUID`. It is an absolute, real, EUID-owned `0700` directory shared by all cooperating processes.
The logical owner is EUID plus Bash `$$` plus `/proc/$$/stat` start time. This keeps `token=$(harness_lease_acquire ...)` releasable by its parent shell and detects PID reuse. Every normalized key is exclusive across owners for both same and different modes. Only an identical owner/session/request-hash acquire is idempotent; other self-overlap is an error. A bundle publishes and unpublishes at one point, so it is entirely visible or absent.
Wait `0` tries once; `1..300` uses a monotonic deadline and a final no-sleep attempt. Live owners are never preempted. Stale owner bundles are unpublished before reuse. Release verifies token, owner, session, canonical request, and hash before unpublishing the whole bundle. Unpublish atomically renames an active record to a validated tombstone before unlink; an unlink failure returns `2`, leaves the bundle logically inactive, and the next locked operation validates and retries tombstone cleanup before doing other work.
Acquire success is `0`, empty stderr, and one unique token plus LF on stdout. Release success is `0` with both streams empty. Protocol, ownership, state, tool, clock, and I/O failures are `2`, empty stdout, and `error: resource lease operation failed` on stderr. Live contention or timeout is `3`, empty stdout, and `error: resource lease unavailable` on stderr.
