# PLAN v5.5 sizing prototype report

## Question and boundary

Question: if 03a stops owning executable dynamic-race cases, while retaining source validation, static root/path safety, production marker/phase occurrence checks, dependency-absent behavior, and the task-4 dispatcher fixes, can its two-file implementation remain shfmt-clean and within the immutable `400`-line exact2 gate?

This was a read-only/throwaway prototype against implementation HEAD `fad7bf384d9d8807f1f268649bc8ed19e10cf4b0`. `tests/test-session-path.sh` was copied into `/tmp/03a-v55-sizing.vN7I4L`; all removal, repair, formatting, execution, and extraction happened there. Neither implementation file was edited or committed.

## Mechanical slice

Starting from the HEAD test, the temporary candidate made only these boundary changes:

- Removed `mutations` from accepted `--case` values and from the default child dispatcher.
- Removed the complete executable `if [[ $GROUP == mutations ]]` body.
- Retained the three production-anchor exact-occurrence checks and the `before_mkdir` / `after_eexist` / `before_open` phase-occurrence checks as `check_structure`, executed by normal functional groups.
- Retained `source-validate`, `roots-static`, and `--dependency-absent`.
- Applied the round-1 dispatcher candidate: only provider is globally mandatory; when foundation is genuinely absent, default and `--dependency-absent` route to all-missing inert; when foundation exists, default runs only `source-validate` and `roots-static`.
- Applied the exact stream candidate: each default child stdout is compared with `cmp` against a file containing exactly one `SUMMARY` line plus one LF; stderr must be empty and child rc must be zero.
- Removed the unused `invoke` label local. The SC2053 site disappeared with the dynamic mutation body.

## Retained case inventory

- `source-validate`: source-side-effect inventory, present dependencies, each of the three missing foundation functions, all-missing dependency mode, exact private function surface, public API absence, real validation order, fake `python3` non-invocation, and self-disproving failure injection.
- `roots-static`: HARNESS/XDG/TMP/default selection and precedence, physical path behavior, post-mkdir disappearance, dangerous-root rejection with zero creation, 2x2 project/session isolation, and static link/file/mode rejection at root/project/session layers.
- Structure: all three production marker anchors exactly once, all three checkpoint phases exactly once, and no `fchmod`.
- Dependency absence: explicit flag and genuinely foundation-absent default both run the real all-missing inert source oracle.
- Default dispatcher: exactly `source-validate` then `roots-static`, with exact stdout/stderr/rc propagation and unchanged-foundation check.

## Removed case inventory

The complete executable dynamic mutation group was removed from 03a:

- safe-directory / symlink / regular-file swaps at the root open checkpoint;
- EEXIST safe winner, unsafe winner, and disappearing winner;
- replacement after successful mkdir;
- ordinary mkdir failure;
- wrong-EUID and real `EIO` injections;
- dynamic sentinels, victim/replacement inode/mode/hash/inventory assertions, mutation-copy driver, and its `--case mutations` public test selector.

No source-validation or static-root oracle was removed.

## Runtime checks of the temporary candidate

Each command produced exactly `RESULT PASS  session path safety\n`, empty stderr, and rc `0`:

- normal default;
- `--case source-validate`;
- `--case roots-static`;
- normal `--dependency-absent`;
- genuinely foundation-absent default;
- genuinely foundation-absent `--dependency-absent`.

## 03a1 single-file estimate

A second mechanical extraction placed the current dynamic mutation body together with its required `capture` / `invoke` / `expect`, provider-copy, replacement, inventory, and structural helpers into a standalone temporary race-test skeleton. After pinned shfmt it was **186 lines**, leaving **214 lines** below a per-file `400` gate; pinned ShellCheck warning gate also passed.

The planned root/project/session and safe-dir/link/file expansion should remain data-driven over layer/kind matrices rather than duplicate case bodies. Allowing roughly 15–25 lines for the dependency-absent/final dispatcher and 30–50 lines for the expanded matrices still projects about 231–261 lines. Therefore a single `tests/test-session-path-races.sh` is credibly `<=400`, with at least roughly 139 lines of estimated margin. This estimate ceases to hold if the three layers are implemented as copied test bodies instead of shared loops/helpers.

## Verdict

The proposed v5.5 split is mechanically viable: 03a becomes shfmt-clean at `388/400`, and the extracted 03a1 race slice has a credible single-file path below `400`.
